# 配置说明 —— 各项配置怎么配

本文件逐项说明所有可配置参数：在哪配、默认值、含义、怎么调。配完**重启后端生效**（按会话覆盖项除外，见第 5 节，即时生效）。

---

## 1. 配置入口总览（三个来源，优先级从低到高）

| 来源 | 位置 | 适用 | 生效方式 |
|---|---|---|---|
| ① 环境变量 | shell `export` | 密钥等敏感项 | 启动时读取 |
| ② 配置文件 | `backend/src/main/resources/application.yml` | 全局默认值 | 重启后端 |
| ③ 按会话覆盖 | 前端 `useAsrRecorder({...})` → `start` 消息 | 单次收音临时调参 | 即时，仅当次会话 |

> 同一项三处都给时，③ 覆盖 ②，② 覆盖内置默认。①（API Key）只走环境变量。

环境变量目前只有一个（**必填**）：
```bash
export DASHSCOPE_API_KEY=sk-xxxx     # 阿里百炼 API Key，仅后端读取，绝不下发前端
```

## 2. DashScope 识别参数 `asr.dashscope.*`

控制转写引擎本身的行为，直接影响**准确率与完整性**。

| 配置项(yml) | 默认 | 含义 | 怎么配 |
|---|---|---|---|
| `endpoint` | `wss://dashscope.aliyuncs.com/api-ws/v1/inference/` | 服务地址 | 海外用 `dashscope-intl.aliyuncs.com` |
| `api-key` | `${DASHSCOPE_API_KEY:}` | 鉴权 Key | 用环境变量注入，别写死 |
| `model` | `fun-asr-realtime` | 模型名 | 一般不改 |
| `sample-rate` | `16000` | 采样率 | 必须与前端音频一致(16k)，**别动** |
| `format` | `pcm` | 音频格式 | 与前端一致，**别动** |
| `max-sentence-silence` | `800` | VAD 断句静音阈值(ms)：停顿超过它就断一句 | **想少切碎长句→调大(如 1200~2000)**；想更快出句→调小 |
| `punctuation-prediction-enabled` | `true` | 自动加标点 | 一般保持 true |
| `heartbeat` | `true` | 静音期保活 | 保持 true |
| `connect-timeout-ms` | `8000` | 连接超时 | 弱网可调大 |

### 识别调优（M2/M3，默认**不下发**，按需开启）
> 这几项默认注释掉/为空 → 用模型默认行为。不确定模型是否支持时保持关闭最稳。开启方式：取消 yml 注释并填值。

| 配置项(yml) | 含义 | 何时开 |
|---|---|---|
| `vocabulary-id` | 热词表 ID（在百炼控制台创建词表后得到） | **专有名词/人名/术语多**时开，显著提准 |
| `semantic-punctuation-enabled` | 语义断句（按语义而非纯静音断句） | 句界不自然、长句被切碎时试开 |
| `disfluency-removal-enabled` | 顺滑：去除“嗯/啊/那个”等口水词 | 要干净文本做分析时开 |
| `inverse-text-normalization-enabled` | ITN：把“一百二”规整成 `120`、日期/单位规整 | 下游要结构化数字时开 |
| `language-hints` | 语种提示，如 `[zh, en]` | 中英混说时填 |

示例（yml 开启热词 + 顺滑）：
```yaml
asr:
  dashscope:
    vocabulary-id: vocab-xxxxxxxx
    disfluency-removal-enabled: true
    language-hints: [zh, en]
```

### M4 稳定性（`asr.dashscope.*` 续）
| 配置项 | 默认 | 含义 | 怎么配 |
|---|---|---|---|
| `session-max-seconds` | `600` | 单任务时长上限前主动滚动重开 | 接近你账号的单任务上限设；`<=0` 关闭滚动 |
| `reconnect-base-ms` | `1000` | 断线重连退避基数 | 弱网可调大 |
| `reconnect-max-ms` | `16000` | 退避上限 | — |
| `max-reconnect-attempts` | `8` | 连续重连失败上限，超过上报致命错误 | 想更顽强可调大 |
| `audio-buffer-frames` | `200` | 重连/切换间隙音频缓冲帧上限(约 20s@100ms) | 弱网久断可调大(占内存) |

## 3. 聚合触发器 `asr.aggregator.*`（决定"攒多少、何时送后端"）

任一触发器命中即打包一批送分析后端。`<=0` 表示关闭该触发器。**所有切批都对齐定稿句，不切半句。**

| 配置项 | 默认 | 含义 | 怎么配 |
|---|---|---|---|
| `char-threshold` | `200` | 累计字数达到即上报（主"攒够"手段） | 想每批内容更多→调大(如 400)；想更碎更快→调小 |
| `sentence-threshold` | `0`(关) | 累计句数达到即上报 | 按"每 N 句"分析时开 |
| `interval-ms` | `8000` | 周期上报间隔，防说太久不报 | 实时性优先→调小(如 3000) |
| `silence-flush-ms` | `1500` | 说话停顿超过它就在自然边界切批 | 想在停顿处自然分段→保持/调小 |
| `max-buffer-ms` | `15000` | 最大滞留兜底(强制，忽略下面最小批) | 内容不能滞留太久→调小 |
| `min-chars-to-flush` | `10` | 时间/停顿触发时的最小批字数，防碎批 | 嫌碎批多→调大 |
| `overlap-sentences` | `1` | 批间携带上一批末尾 N 句作上下文 | 下游需跨批上下文→调大(如 2) |

## 5. 按会话覆盖（前端，临时调参，即时生效）

在前端 `useAsrRecorder(config)` 传入；聚合触发器写在顶层，识别参数写在 `recognition` 里。**只覆盖你写的字段，其余仍用后端默认。**

```ts
const { start, stop } = useAsrRecorder({
  // 聚合触发器覆盖
  charThreshold: 300,
  intervalMs: 5000,
  silenceFlushMs: 1200,
  overlapSentences: 2,
  // 识别参数覆盖
  recognition: {
    maxSentenceSilence: 1500,
    vocabularyId: 'vocab-xxxxxxxx',
    disfluencyRemovalEnabled: true,
    languageHints: ['zh', 'en'],
  },
});
```

对应到 `start` 消息（前端自动发，了解即可）：
```json
{ "type": "start", "sessionId": "sess_xxx",
  "config": {
    "charThreshold": 300, "intervalMs": 5000,
    "recognition": { "maxSentenceSilence": 1500, "vocabularyId": "vocab-xxxxxxxx" }
  } }
```

## 6. 常见调优场景（直接照着配）

**A. 要内容尽量完整、不被切半句**
- `asr.dashscope.max-sentence-silence`: `1500`（停顿久一点才断句）
- `asr.aggregator.char-threshold`: `400`、`silence-flush-ms`: `1500`、`overlap-sentences`: `2`

**B. 实时性优先（尽快送后端）**
- `asr.aggregator.interval-ms`: `3000`、`silence-flush-ms`: `800`、`char-threshold`: `120`

**C. 专业领域（人名/术语多）**
- 控制台建热词表 → `asr.dashscope.vocabulary-id` 填表 ID
- 可叠加 `disfluency-removal-enabled: true` 出干净文本

**D. 长时间会议录音**
- `asr.dashscope.session-max-seconds` 按账号单任务上限设（如 `1800`），滚动会话防断流
- `asr.dashscope.audio-buffer-frames`: `400`（弱网切换更稳）

**E. 弱网/易断**
- `reconnect-max-ms`: `30000`、`max-reconnect-attempts`: `12`、`audio-buffer-frames`: `400`
- 投递端 `queue-dir` 指向持久盘，断网批次会落盘并在恢复后自动续传

## 7. 前端常量（`frontend/src/hooks/useAsrRecorder.ts`）

| 常量 | 默认 | 含义 |
|---|---|---|
| `MAX_RECONNECT` | `8` | 前端↔代理最大重连次数 |
| `RECONNECT_BASE_MS` / `RECONNECT_MAX_MS` | `1000` / `16000` | 前端重连退避 |
| 心跳间隔 | `15000`(ms) | `AsrSocket` 构造参数 `heartbeatMs` |
| 音频帧长 | `100`(ms) | `recorder.start(..., { frameMs: 100 })` |
